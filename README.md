# EIF509 · Demo Sesión 11 — Rama `inicio`: la API sin autenticación

Esta rama es el **punto de partida** de la Demostración 1 de la Sesión 11.
Contiene el proyecto de la
[Sesión 10](https://github.com/adriangarro/eif509-demo-sesion10) sin cambios:
la API (`/api/**`) responde a cualquier petición, sin credenciales.

La versión completa, con autenticación JWT, roles, CORS y la SPA en React,
está en la rama `main`, cuyo README explica cada paso:

```bash
git switch main
```
