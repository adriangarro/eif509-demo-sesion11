# SPA en React del catálogo (Sesión 11)

Aplicación de una sola página que consume la API de este repositorio.
Las instrucciones completas están en el [README principal](../README.md),
sección «Demostración 2».

```bash
npm install
npm run dev
```

Se abre en `http://localhost:5173`. La API debe estar en ejecución en
`http://localhost:8080`.
